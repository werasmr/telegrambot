# 📈 AI-генератор торговых сигналов для бинарных опционов

Готовое приложение на Python + Streamlit, которое генерирует сигналы
**ВВЕРХ (CALL)** / **ВНИЗ (PUT)** / **СТОИМ НА МЕСТЕ** на основе:

- **Технического анализа** — минутные/5-минутные свечи с Yahoo Finance
  (`yfinance`), индикаторы RSI(14), MACD, Bollinger Bands, EMA(9)/EMA(21);
- **Новостного фона** — свежие заголовки из ~20 RSS-лент: Yahoo Finance,
  Investing.com (Forex/Economy/Indicators/Stocks), CNBC, MarketWatch,
  Bloomberg, FXStreet, FXEmpire, ForexLive; для крипты дополнительно
  CoinDesk, Cointelegraph, Decrypt, Bitcoin Magazine, CryptoPotato.
  Ленты качаются параллельно, недоступные молча пропускаются;
- **ИИ-аналитика** — бесплатная модель **Google Gemini Flash** взвешивает
  индикаторы и новости и выдаёт решение с процентом уверенности,
  рекомендованной экспирацией (1–5 минут) и кратким обоснованием.

Поддерживаемые активы: **EUR/USD**, **GBP/USD**, **BTC/USD**.

## Структура проекта

| Файл | Назначение |
|---|---|
| `data_engine.py` | Загрузка свечей через `yfinance` и расчёт индикаторов (`ta`) |
| `news_engine.py` | Парсер финансовых новостей из RSS-лент (`feedparser`) |
| `ai_engine.py` | Интеграция с Google Gemini API (автоподбор доступной Flash-модели) |
| `main.py` | Веб-интерфейс на Streamlit + графики Plotly |
| `requirements.txt` | Зависимости проекта |

## Установка

```bash
git clone <ваш-репозиторий>
cd <папка-проекта>

python -m venv .venv
source .venv/bin/activate        # Windows: .venv\Scripts\activate

pip install -r requirements.txt
```

## 🔑 Куда вставить GEMINI_API_KEY

1. Получите **бесплатный** ключ в Google AI Studio:
   👉 <https://aistudio.google.com/apikey>
   (нажмите **Create API key** — регистрация карты не требуется).

2. Укажите ключ **любым** из способов:

   **Способ 1 — переменная окружения (рекомендуется):**

   ```bash
   # Linux / macOS
   export GEMINI_API_KEY="ваш_ключ_сюда"

   # Windows (PowerShell)
   $env:GEMINI_API_KEY="ваш_ключ_сюда"
   ```

   **Способ 2 — прямо в интерфейсе:**
   запустите приложение и вставьте ключ в поле **«GEMINI_API_KEY»**
   в боковой панели слева (поле скрывает ввод, как пароль).

## Запуск

```bash
streamlit run main.py
```

Откроется браузер (обычно <http://localhost:8501>):

1. В боковой панели выберите **актив** (EUR/USD, GBP/USD, BTC/USD)
   и **таймфрейм** свечей (1m или 5m).
2. Нажмите **«🚀 ПОЛУЧИТЬ СИГНАЛ»**.
3. Приложение скачает свечи, посчитает индикаторы, соберёт 5 свежих
   новостей и передаст всё Gemini. На экране появятся:
   - огромная **зелёная стрелка ВВЕРХ (CALL)** или **красная ВНИЗ (PUT)**;
   - рекомендованное **время экспирации** (1–5 минут);
   - **процент уверенности** ИИ;
   - **краткое обоснование** решения;
   - свечной **график Plotly** с EMA, полосами Боллинджера, RSI и MACD;
   - список новостей и точная сводка, отправленная в модель.

## Проверка модулей по отдельности

```bash
python data_engine.py   # скачает свечи и напечатает сводку индикаторов
python news_engine.py   # напечатает 5 свежих заголовков новостей
python ai_engine.py     # тестовый запрос к Gemini (нужен GEMINI_API_KEY)
```

## Примечания

- Данные форекс (EUR/USD, GBP/USD) на Yahoo Finance доступны только когда
  рынок открыт (пн–пт); BTC/USD торгуется круглосуточно.
- Бесплатный тариф Gemini имеет лимиты запросов в минуту — при ошибке 429
  подождите немного и повторите запрос.
- Google периодически закрывает старые модели для новых ключей, поэтому
  `ai_engine.py` перебирает список `MODEL_CANDIDATES`
  (`gemini-flash-latest` → `gemini-3.5-flash` → `gemini-3-flash-preview` →
  `gemini-2.5-flash`) и использует первую доступную. Если все модели из
  списка перестали работать — допишите актуальное имя из
  [списка моделей Gemini](https://ai.google.dev/gemini-api/docs/models)
  в начало `MODEL_CANDIDATES`.
